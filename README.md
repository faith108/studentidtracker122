# Student ID Tracking and Recovery Management System

## Developed By
Faith Wanjiru

## Institution
Murang'a Technical Training Institute

## Project Description
The Student ID Tracking and Recovery Management System is a web-based application that enables students to report lost student identification cards, check the recovery status, and receive updates from the administrator. The system helps reduce paperwork and improves the efficiency of the ID recovery process.

## Features

- Student Registration
- Student Login
- Administrator Login
- Report Lost Student ID
- Search Lost ID Status
- Notifications
- Admin Dashboard
- Student Management
- Lost ID Management
- Reports

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP

## Installation

1. Download or clone this repository.
2. Copy the project into the `htdocs` folder.
3. Import `database/studentidtracker122.sql` into phpMyAdmin.
4. Update `config.php` if necessary.
5. Start Apache and MySQL.
6. Open:

http://localhost/studentidtracker/
